## Collaborate on research papers

Paper Guide helps research teams work together with real-time editing, inline comments, and role-based access controls for every paper and workspace.

## Real-time editing

Multiple team members can edit the same paper simultaneously. Live cursors show where other collaborators are working, while conflict-free syncing combines changes without requiring manual version merging.

Paper Guide also supports offline editing, so you can continue working without an internet connection.

<Callout kind="info">

Changes made while offline sync automatically as soon as you reconnect. Paper Guide merges edits without overwriting concurrent work.

</Callout>

## Comments and annotations

Add inline comments directly to specific text passages so collaborators can review claims, suggest revisions, or ask questions in context. Threaded replies keep each discussion together instead of spreading feedback across separate messages.

Use `@mentions` to notify specific team members about a comment. When a discussion is complete, resolve the comment to remove it from the active review view. Resolved comments remain in the comment history for reference.

## Roles and permissions

Assign each collaborator a role that matches their responsibilities in the workspace.

| Role       | Can View | Can Comment | Can Edit | Can Manage Members | Can Delete Papers |
| ---------- | -------- | ----------- | -------- | ------------------ | ----------------- |
| **Owner**  | ✓        | ✓           | ✓        | ✓                  | ✓                 |
| **Editor** | ✓        | ✓           | ✓        | ✗                  | ✗                 |
| **Commenter** | ✓      | ✓           | ✗        | ✗                  | ✗                 |
| **Viewer** | ✓        | ✗           | ✗        | ✗                  | ✗                 |

<Callout kind="alert">

Only the workspace Owner can transfer ownership or delete the workspace entirely.

</Callout>

## Sharing methods

Choose a sharing method based on whether collaborators need an account, editing access, or open access to the workspace.

<Tabs>
  <Tab title="Share Link">

  Generate a read-only or comment-enabled link from workspace settings. Set an expiration date for time-limited access, and revoke links at any time. Share links work well for external reviewers who do not need a Paper Guide account.

  </Tab>
  <Tab title="Email Invite">

  Invite collaborators by email from **Settings → Members**. Assign a role of Owner, Editor, Commenter, or Viewer, then include a personalized message. Invitees receive an email with a direct join link.

  </Tab>
  <Tab title="Public Workspace">

  Publish a workspace publicly for open-access collaboration. Public workspaces are viewable by anyone with the link and can optionally allow public comments. Toggle public access on or off from workspace settings.

  </Tab>
</Tabs>
