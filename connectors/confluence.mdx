## Overview

Use the Confluence integration to connect your Atlassian account and make Confluence available as an AI agent context source. The Documentation AI agents read Confluence pages live at runtime. When a prompt needs context from confluence, the agent queries Confluence on demand with CQL, then reads the relevant pages directly.

## Before you start

<Callout kind="info" collapsed="false">
  You need:

  - The **Admin** or **Editor** role in your Documentation.AI organization
  - An Atlassian account with access to the Confluence content you want the agent to use
  - At least one documentation project created in your Documentation.AI workspace
</Callout>

## Connect Confluence

<Steps>
  <Step title="Open Agent Settings" icon="bot" title-type="p">
    In the dashboard sidebar, under **AI**, click **Agent Settings**. The **Connectors** section lists the tools the agent can pull context from.

    If you are in the editor, you can click **Connectors** below the chat input instead. It opens the same list.
  </Step>

  <Step title="Click Connect on the Confluence card" icon="plug" title-type="p">
    Atlassian opens in the same tab. Sign in if Atlassian asks you to.
  </Step>

  <Step title="Complete the Atlassian OAuth flow" icon="lock" title-type="p">
    Choose the Confluence site and approve access. Atlassian sends you back to the page you started from, and "Connected successfully" appears.
  </Step>

  <Step title="Check that the connector is on" icon="toggle-right" title-type="p">
    The Confluence card now shows your Confluence site name, **Manage**, and a switch that is on. Confluence is now on for the documentation project you have open, so the Writer and Answer agents can query it.
  </Step>
</Steps>

<Callout kind="info" collapsed="false">
  The Confluence connection belongs to your organization, but the switch is set per documentation project. To use Confluence in another project, open that project, go to **Agent Settings**, and turn on the Confluence switch.
</Callout>

## How the AI agent uses Confluence

The Confluence subagent uses these tools to find and read the content your prompt needs.

| Tool              | What it does                                                      |
| ----------------- | ----------------------------------------------------------------- |
| `listSpaces`      | Lists all Confluence spaces accessible to the connected account   |
| `searchPages`     | Searches pages using CQL by text, space, label, or other criteria |
| `getPage`         | Fetches full content of a single page by ID                       |
| `listSpacePages`  | Lists pages within a specific space                               |
| `getSpaceTree`    | Retrieves the page tree hierarchy for a space                     |
| `getPageChildren` | Lists child pages under a specific page                           |
| `getPageLabels`   | Lists labels attached to a page                                   |

The agent decides which tools to call based on your prompt. For example, it may search with CQL first, inspect a space tree to narrow the scope, then fetch one or more pages to answer a question or write documentation.

## Example prompts

Use prompts like these when you want the AI agent to pull context from Confluence:

- Summarize the deployment process documented in our Platform Engineering space.
- Find Confluence pages about SSO setup and update the authentication guide to match them.
- Search for pages labeled onboarding and draft a getting-started checklist for new support agents.
- Compare the incident response steps in Confluence with the current runbook in this documentation project.

## Troubleshooting

Use these checks if the Confluence integration or project connector is not behaving as expected.

<ExpandableGroup>
  <Expandable title="Confluence card is missing from Agent Settings" default-open="false">
    If you cannot find the **Confluence** card:

    - Open **Agent Settings** from the **AI** section of the dashboard sidebar, and look in the **Connectors** section.
    - Confirm you have the **Admin** or **Editor** role in your organization. Refresh the dashboard if your role changed recently.
  </Expandable>

  <Expandable title="Agent cannot find Confluence pages" default-open="false">
    If the agent returns weak results or cannot find expected pages:

    - Confirm the connected Atlassian account can open those pages directly in Confluence.
    - Check whether the pages live in the expected space and whether your prompt includes enough detail, such as a space name, page title, or label.
    - Check that the Confluence switch is on in **Agent Settings** for the current documentation project, not only connected for your organization.
    - Retry with a narrower prompt, such as asking for a specific space or topic, so the agent can form a more precise CQL query.
  </Expandable>

  <Expandable title="Confluence switch is missing for a project" default-open="false">
    The switch appears after Confluence is connected. If the card shows **Connect** instead, Confluence is not connected for your organization yet. Refresh **Agent Settings** after you finish connecting.
  </Expandable>
</ExpandableGroup>
